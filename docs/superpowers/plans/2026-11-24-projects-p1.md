# Projects P1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Projects tab with idea evaluation against profile + job gaps, and the MCP tools the `/fechar-projeto` skill needs.

**Architecture:** New package `today/projects/` (`repo.py`, `gaps.py`, `evaluate.py`, `routes.py`), migration 007,
templates `projects.html` + `_projects_split.html` on the existing split layout, MCP tools in `mcp_server.py`.
Evaluation reuses `app.state.analyst` (ADR 0007) with `PROJECTS_MODEL` (default `opus`).

**Spec:** `docs/features/10-projects.md` (contracts, acceptance tests).

## Global Constraints

- Repo is public: tests use fake profiles and fake analysts only.
- Only design tokens from `docs/design.md`; strings in pt and en through `t()`.
- Evaluation errors never lose the idea: the project row is written before the analyst is called.

## Review Focus

- Analyst off (`ANALYST` unset) → page works, says evaluation is unavailable → Task 3.
- Empty profile → evaluation still runs (gaps + projects), prompt says profile is empty → Task 2.
- No analyzed jobs yet → `gap_stats` empty, prompt says so instead of inventing gaps → Task 2.
- Idea text with HTML → escaped on the page (autoescape; no `|safe`) → Task 3.
- Double submit of the new-idea form → two projects is acceptable; no crash → covered by create test.
